# AIM Joystick Probe v1.2.2

Updating is now built in, the same way it works in the Invictus Livery Manager.

## What's new
- **Download updates in the app:** when a new version is out, the banner at
  the top of the window says so. Click **Download** and the Probe downloads the
  installer itself, showing its progress in the banner. When it's done, click
  **Run installer**. The installer closes the Probe before it updates it.
- **View release notes** in the banner opens the release page, like this one.
- **Check for updates:** open Settings (the gear at the top right). The new
  **Software** section shows your version and a **Check for updates** button.

Updating to 1.2.2 itself still opens this page in your browser. From the next
version on, updates download inside the app.

## Install

Download **AIM-Joystick-Probe-v1.2.2-Setup.exe** below and run it. It installs
over your existing copy and keeps your settings. The installer and the app are
code-signed by Invictus Machine LLC, and it installs per-user with no
administrator rights needed.
